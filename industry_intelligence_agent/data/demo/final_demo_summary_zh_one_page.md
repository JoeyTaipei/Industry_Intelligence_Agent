# 一頁式面試展示內容：Industry Intelligence Agent

## Demo 情境

顧問團隊需要在短時間內理解「台灣半導體 / AI Server 產業」的成長動能、商業風險與數位轉型機會。本專案示範如何用 Python 自動整理公司資料、新聞、年報片段、產業趨勢與 KRI 風險證據，並產出可放進簡報與儀表板的結構化成果。

## 我解決的問題

- 產業研究資料分散在新聞、年報、公司資料與產業報告中，人工整理耗時。
- 顧問簡報需要的不只是摘要，而是「事實、分析解讀、建議追問」的清楚區分。
- 數位轉型建議必須連結真實商業風險與可衡量 KPI，而不是只談技術。

## Demo 輸入資料

- 公司：TSMC、MediaTek、Quanta、Wistron、Foxconn、Cathay Financial、Fubon Financial
- 產業：semiconductor、AI server、manufacturing、financial services
- 資料：公司基本資料 CSV、樣本新聞、年報文字片段、產業趨勢 JSON、KRI Evidence Table

## 核心產出

- **Industry Intelligence Brief：** 顧問式產業與公司研究報告
- **Business Signal Extraction：** 從新聞與文件萃取成長、風險與營運訊號
- **KRI Evidence Table：** 依 supply chain、inventory、customer concentration、geopolitical、cyber、ESG 等風險分類
- **Dashboard-ready KPI/KRI Table：** 可直接用於 Streamlit、Excel、Power BI 或簡報
- **Digital Transformation Opportunity Map：** 將風險轉成數位轉型機會

## 主要洞察

- **來源事實：** AI server 需求帶動先進半導體、伺服器組裝與電子製造供應鏈機會。
- **分析解讀：** 成長同時帶來供應鏈、庫存、客戶集中度、地緣政治與資安風險。
- **商業意涵：** 數位轉型機會應聚焦在需求預測、供應商風險監控、營運資金儀表板、資安監控與 ESG 資料治理。
- **建議追問：** 客戶目前追蹤哪些 KRI？資料在哪裡？哪些流程最需要即時風險可視化？

## 為什麼適合 Deloitte Digital Technology

這個專案不只是技術練習，而是把資料工程、Python 分析、KRI 風險思維、GenAI guardrails 與顧問式溝通結合起來。它展示我能從商業問題出發，設計可擴充的資料流程，並把分析結果轉化為客戶能理解、能追問、能行動的數位轉型方向。

## 面試時我會強調的一句話

我希望用資料與 AI 幫助顧問團隊更快看見重點、更有依據地提出問題，並把產業研究轉化為可衡量的數位轉型機會。
